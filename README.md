# Modulo-Contable

Bienvenido al manual de uso del Modulo contable, aquí se detallaran los pasos de instalación y uso del programa.

# Instalación.

Cuando finalice la descarga de la carpeta, esta se encontrara en formato zip. Puede usar el descompresor por defecto del explorador de Windows, o usar programas como Winrar o 7-zip.

Antes de empezar a usar el programa debe contar con motor de base de datos para los archivos .sql, ya que estos contienen todas las cuentas del catalogo por defecto, además de permitirle al programa crear y manipular los asientos contables. NOTA: El modulo solo funciona con el motor MySQL, cualquier otro motor de bases de datos no podrá conectarse e interactuar con el programa, además necesitara de un administrador de bases de datos como MySQL Workbench (RECOMENDADO), para ejecutar los archivos .sql que contienen las cuentas, además de el formato de los asientos contables.

# Uso.

Al iniciar el programa, este le mostrara un panel de inicio que le informara de todos los cambios hechos recientemente, como cuentas activas, asientos creados, ventas del mes. Junto una tabla que muestra los ultimos asientos contables que ha creado y las cuentas que mas ha usado.

Al lado izquierdo de este se encuentra un menu con todas las demas opciones que el modulo ofrece.

La opción de catalogo de cuentas permite la creación de nuevas cuentas para que pueda usar, además de eliminar las que ya no necesite. 

El libro diario puede crear y eliminar asientos contables. Puede usar las cuentas por defecto en sus asientos y las que ha creado usando el modulo.

La Mayorización le permite hacer el proceso de manera automática en todos los asientos que selecione.
